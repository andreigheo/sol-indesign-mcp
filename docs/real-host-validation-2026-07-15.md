## Why this is not a release pass

1. The repository has no initial Git commit, so evidence cannot yet be tied to an immutable source revision.
2. The exact step-10 preview target was occupied by an earlier failed tool call; the successful retry used a new path.
3. A corrective bounds batch occurred after the artwork-creation batch. Therefore the top InDesign Undo entry reverts bounds rather than removing the rectangle and text frame, and step 14 cannot prove the required one-step creation-batch Undo.

The final post-fix native-Windows `pnpm verify && pnpm doctor` run passed: 246 unit tests, 18 contract/mock-E2E tests, type checking, lint, builds, stdout purity, bundle/package checks, credential/ACL checks, and doctor required checks. The expected doctor bridge warning occurred because the short-lived STDIO server had already exited.

The next release-readiness attempt must use a new empty workspace, a newly created document, the exact artifact names from the manual, no corrective mutation after step 9, and one final Undo with before/after evidence.
